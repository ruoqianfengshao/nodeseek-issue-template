# NodeSeek Issue Templates

为 NodeSeek 准备的 Tampermonkey 脚本。核心能力是通过表单快速生成单机或多机交易帖的标题与 Markdown，减少重复填写，让配置信息更清晰、交易内容更易读；此外还提供抽奖配置与开奖跟踪、交易状态切换、回复楼层追踪、关键字过滤等日常功能。

## 安装

在 Tampermonkey 中直接安装：[NodeSeek Issue Templates.min.user.js](https://github.com/ruoqianfengshao/nodeseek-issue-template/releases/latest/download/NodeSeek.Issue.Templates.min.user.js)。

脚本在 NodeSeek 各页面提供对应功能：发帖与编辑页有“出🐔模板”“收🐔模板”和“🎁 抽奖配置”，帖子页有抽奖跟踪、交易状态与「我的回复」，列表页有关键字过滤。

## 界面

发帖页面提供两个独立入口：**“出🐔模板”**用于发布出售帖，**“收🐔模板”**用于发布收购帖，两者互不影响，按需要打开即可。

## 功能

### 出🐔模板

- 支持厂商、型号、CPU、内存、硬盘、带宽、流量等配置的选择、匹配和自由新增
- 支持单机、多机书签编辑与统一标题生成
- 支持剩余价值计算、续费金额人民币换算和实时汇率；可选择是否导出价值卡片
- 支持预出总价与溢价二选一校验及价格预览
- 支持填写 NodeSeek / TQ 地址，以及常用标签快捷选择
- TG 地址本地缓存：填写一次后可自动回填
- 支持文本和表格两种 Markdown 导出格式
- 支持新帖与编辑已有帖子；重新编辑时会把正文还原成表单，方便继续调整

### 收🐔模板

- 填写目标机器的厂商、型号、CPU、内存、硬盘、带宽、流量，同样支持候选项与自由输入
- 内置机器配置库：可搜索已登记配置，选中型号后自动回填整套配置
- 支持续费金额与周期，便于对方判断机器价值
- 收购方式可选：剩余价值收、剩余价值折收、剩余价值加价收、剩余价值减额收、总价收、带价聊
- 支持交易标签（原邮 / 改邮、包中介 / 不包中介、先机后款 / 先款后机、站内私信）与自定义标签
- 标题同样支持字段选择与排序，可填写常用备注并自动带入
- 填写 TG 联系方式，方便对方联系

### 抽奖

- 发帖时可一键生成抽奖信息并写进正文，开奖链接自动指向正确的帖子地址
- 帖子页跟踪自己发起与参与过的抽奖，已到开奖时间提醒你公布名单、中奖后提醒你去查看
- 开奖后一键公布中奖名单：自动改写帖子标题并追加 @ 中奖人
- 详见[抽奖](#抽奖)与[抽奖跟踪](#抽奖跟踪)

### 帖子辅助

- **交易状态**：自己发布的交易帖在楼层旁提供「已出 / 不出了」（出售帖）或「已收 / 不收了」（收购帖）按钮，一点即可切换标题状态
- **我的回复**：在帖子页列出自己在该帖回复过的楼层，可直接跳转；列表页则标记出回复过的帖子
- **关键字过滤**：按关键字隐藏列表页里不想看的帖子

## 抽奖

发帖页「发布」按钮旁有独立的「🎁 抽奖配置」入口，只对当前页面这一次发布生效，重新打开发帖页就要重新填：

- 设置开奖时间（默认 24 小时后）、奖品数量、起始楼层与楼层去重；开奖时间旁实时显示还剩多久
- 参与方式支持任意回复、包含回复、固定回复，并可叠加点赞、鸡腿等互动条件
- 参与方式不是任意回复时，可勾选「不满足条件时顺延至下一位」
- 抽奖信息可以写在正文末尾或开头，参与方式、开奖时间、中奖人数可逐项决定是否展示
- 标题默认 `# 🎁 抽奖信息`，支持 Markdown，留空则不写标题行
- 弹窗内实时预览将要写进正文的内容

点「保存本次抽奖」会把这块模板插入正文，你可以在编辑器里自行审阅、调整位置或补充说明。之后照常用 NodeSeek 的「发布」按钮发帖，发布成功后脚本会自动把开奖链接补成指向这篇帖子的正确地址，其余内容一律不动，并记下这次抽奖供后续跟踪。

几点行为约定：重复保存会替换上一次插入的那一块，不会堆叠；如果正文里那块被手动改过、或刷新后旧配置已失效，保存时会二次弹窗让你选择「保留编辑器内容」还是「强制覆盖」（强制覆盖会删掉旧的那块再按本次配置插入）。想把抽奖撤掉，直接把正文里那块模板删掉即可。

抽奖链接使用 NodeSeek 官方 [抽奖程序](https://www.nodeseek.com/lucky) 的格式。NodeSeek 的抽奖工具仅按楼层计算，点赞、鸡腿和回复内容只能写进说明，需要自行核对。

## 抽奖跟踪

帖子页右侧面板会多出「抽奖」与「中奖」两个条目，数字分别是待办数量和未读中奖数：

| 条目 | 计数条件 |
| --- | --- |
| 抽奖 | 我发起的抽奖中，已到开奖时间、有中奖名单但正文还没 @ 全部中奖人的帖子数 |
| 中奖 | 我参与过的抽奖中，已开奖且我在名单里、还没点开看过的帖子数 |

点开条目可以看到对应列表：「我发起的抽奖」按帖子列出状态、中奖人名单和开奖链接；「中奖记录」只列我中奖的帖子。

**跟踪范围**

- **我发起的抽奖**：不限于用「抽奖配置」发布的帖子。手动发起、后来编辑补上开奖链接的帖子，同样会被跟踪。
- **我参与的抽奖**：在别人的抽奖贴里回复并发布，就记为参与。开奖后没中奖的记录会自动清理，不会留在列表里。

**公布中奖名单**

已到开奖时间后，帖子 #0 楼层旁会出现「公布中奖名单」按钮，点击后一次性完成两件事：把标题改成 `【已开奖】原标题`，并在正文末尾追加中奖名单（`@名字 [#楼层](链接) 恭喜中奖🎁`）。

**列表管理**

「我发起的抽奖」与「中奖记录」的每条记录右侧都有「删除」按钮。其中「待公布」的记录删除前会二次确认——它代表一件还没做完的事，删掉就没有提醒入口了；未开奖的记录不提供删除（结果还没出，删了就追踪不到）。

**其它约定**

- 中奖名单直接取 NodeSeek 官方抽奖页的结果，脚本不自行计算中奖人
- 帖子开奖后会持续留意名单变化，例如楼主后来才补 @ 中奖人
- 记录保存在本机浏览器，不随账号同步

## 配置共建

机器型号和市场变化很快，因此脚本提供了可选的配置共建机制。

勾选出🐔模板里的“授权检查配置并提示”后，生成出售帖时会检查当前机器配置；配置库里没有的会被登记为新的可复用配置。若不希望提交，取消勾选即可，脚本不会检查或上报机器信息。

![配置提交选项](docs/images/catalog-submission.png)

已登记的配置会记录贡献者，方便查看自己贡献过的机器配置。

![已登记配置](docs/images/catalog-contributions.png)

填写型号时，可根据输入内容搜索已登记配置；选中后会自动回填厂商、型号、CPU、内存、硬盘、带宽、流量、续费周期和续费金额，并展示贡献者昵称。

![配置自动回填](docs/images/catalog-autofill.png)

## 开发

依赖：Node.js 20 或更高版本。

```sh
node tools/build.js build
node --check 'NodeSeek Issue Templates.user.js'
node --check 'NodeSeek Issue Templates.min.user.js'
git diff --check
```

源码位于 `src/`，本地厂商图标在 `assets/vendors/`。根目录的 `NodeSeek Issue Templates.user.js` 与 `NodeSeek Issue Templates.min.user.js` 分别是可读版和压缩版构建产物，不直接编辑；修改源码后执行构建命令。

GitHub Actions 会在推送和 Pull Request 时重新构建，并验证构建产物没有未提交差异。推送 `v*` 标签会自动创建 GitHub Release 并附带两份脚本。

## 共享配置服务

服务端位于 [`worker/`](worker/README.md)，部署到 Cloudflare Workers + D1。部署后将 Worker 地址填入 [`src/config.js`](src/config.js) 的 `MACHINE_CATALOG_API_URL`，再构建并发布 userscript。
